Receiver diagnostics
Radio tuning

Single-bit error correction

Only the hardware Manchester path is corrected. Header and aircraft address stay untouched. An aircraft needs two clean messages and a clean reception within 60 seconds. Recovered fields must pass plausibility checks. Apply updates tracks and TCP output; Observe never does. Main hits/sec and clean totals exclude corrections.

Clean confirmations count recovered payloads later received unchanged with a clean CRC within 10 seconds. Not every legitimate payload repeats.

TCP data output

Connect your local ADS-B software to this receiver. Two clients supported; CRC-valid DF17/DF18 messages only.

Local network, no authentication. Software timestamps support ordering, not MLAT. Beast signal amplitude is unavailable; RSSI remains in the web UI.

Map & aircraft information

Sends the selected ICAO address to adsbdb from this browser. Photos load from Airport-Data.com when available. Reception and the offline map work without internet.

4 Hz position updates with smooth transitions between received fixes. The receiver caches up to 24 trail points for each of 48 aircraft in RAM (about 19 KB). Trails clear on reboot.
