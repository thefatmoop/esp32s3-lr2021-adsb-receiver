# Printable enclosure

- [lid.stl](lid.stl): lid with OLED opening and ADS-B label.
- [back.stl](back.stl): enclosure body/back.

Assembly requires **one M3×8 mm screw**. Reuse the other screws from the
included OLED screen cover: remove that cover and use its screws to secure
the board in the 3D-printed case.

These supplied STL meshes are included unchanged geometrically. STL header
names were normalized to remove embedded local identifiers. STL does not
encode units: inspect dimensions in the slicer and verify fit before printing.
Only meshes are included; no editable CAD design or slicer profile is supplied.

The example build holds its GNSS module and internal 2.4 GHz antenna in place
with hot glue. See the [interior photograph](../../docs/images/interior.png)
and [assembly guide](../../docs/HARDWARE.md).
